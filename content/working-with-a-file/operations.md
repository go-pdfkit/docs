[`ops`](https://github.com/go-pdfkit/ops) is the verb layer: what people
actually do to a PDF they already have. A document here is an ordered list of
pages borrowed from source files, and nothing is applied until it is written.

```go
doc, _ := ops.Open(bytes)
doc.Select("4-6")                 // keep three pages
doc.SetRotation("2", 90)          // turn the middle one
doc.Watermark("all", "DRAFT")
doc.Compress()
out, _ := doc.Bytes()
```

A page range is written `1-3,7,10-` and may say `all`, `even`, `odd` or
`last`. It keeps its own order and its own repeats, so `3-1` reverses three
pages and `1,1` gives two copies.

## The verbs

Merge, select, delete, reverse, move, rotate, crop, resize, split; n-up,
booklet, overlay and underlay, blank pages; watermarks, page numbers, Bates
stamps and free stamps; placing a picture — a signature, a logo, a seal;
sanitize, flatten, strip; compress, encrypt, decrypt and permissions;
straightening a scan; and reading a page back as text or as pictures.

`place` is what "sign a PDF" means in every tool that offers it: a picture of
a signature, put where you say. It is not cryptography and does not claim to
be — a drawn squiggle proves nothing about who drew it.

## Straightening a scan

`deskew` measures how far each page is tilted and turns the crooked ones back.
It **draws** each page to measure it, and reports every page's angle and
whether it was corrected.

```sh
pdfops deskew -list scan.pdf              # just the angles, write nothing
pdfops deskew scan.pdf straight.pdf
pdfops deskew -threshold 0.1 -dpi 300 scan.pdf straight.pdf
```

The angle comes from **Baird's projection profile** (*The skew angle of printed
documents*, Proc. SPSE 1987): the page is sheared rather than rotated — which
keeps the scan-line counts exact, where resampling would blur the very line
structure being measured — and the angle taken is the one that maximises the
variance of the marked-pixel count per scan line.

**The correction is not a rasterisation.** The angle is measured on a render,
but it is applied as a transformation of the page's own content, so text stays
text and a vector drawing stays vector. A deskew that flattened the page would
quietly undo the thing a scan is usually deskewed *for*, which is OCR.

Judged by tesseract, which knows nothing of this code: a rendered page it reads
at 0.968 similarity straight, and at 0.895 tilted by 7°, it reads back at
**0.968** once deskewed — the straight page's own figure.

A page under `-threshold` (half a degree by default) is reported and left
alone, byte for byte. A page with nothing on it has no skew and is reported as
such rather than counted as level: one blank separator sheet does not stop the
rest of a stack being straightened, though a document where *no* page can be
measured is an error rather than a silent success.

`-dpi` is a measurement setting only, since nothing of the render reaches the
output: a higher value buys accuracy and costs time, never quality. Too *low* a
value does silent damage — the projection has to resolve the text lines, and
below about two samples per line pitch it returns an angle that is simply
wrong.

## Forms

A form can be listed, filled in, and **made**.

```go
doc, _ := ops.Open(bytes)
doc.AddFields(
    forms.Field{Name: "applicant", Kind: forms.Text, Required: true,
        Widgets: []forms.Widget{{Page: 1, Rect: [4]float64{72, 700, 300, 720}}}},
    forms.Field{Name: "agree", Kind: forms.Checkbox, Value: "Yes",
        Widgets: []forms.Widget{{Page: 1, Rect: [4]float64{72, 670, 86, 684}, On: "Yes"}}},
)
out, _ := doc.Bytes()
```

The kinds are text, checkbox, radio, button, combo, list and signature. A
field showing in several places is **one** field with several widgets, which is
what a radio group is.

{{< callout type="warning" >}}
A checkbox's drawing is **not** generated by the viewer. `NeedAppearances`
covers text and choice fields, but a button shows whatever its own appearance
dictionary holds for the state it is in — so one written without them is a box
that never looks ticked however often it is clicked. One is drawn per state,
with the path operators rather than with a font, so the document needs no
ZapfDingbats to show a tick.
{{< /callout >}}

Adding to a document that already has a form **joins** it rather than replacing
it: replacing would drop every field the file came with, and the file would
still open.

It refuses before it writes, for each of the things that make a file which
opens and is broken — a field with no name, a choice field with no rows, a
checkbox whose on-state is the reserved name `Off`, two widgets of one radio
group in the same state, a comb field with no `MaxLen`, an empty rectangle, a
page the document does not have, and two fields of one name, which the reader
would silently shadow.

From the command line the same thing reads a description:

```
$ pdfops addfields -fields fields.json blank.pdf form.pdf
added 3 field(s)
$ pdfops fields form.pdf
applicant  text      ""     required
agree      checkbox  "Yes"  buttons [Yes]
```

Links and bookmarks are **carried over** and pointed at the pages they became,
so extracting three pages of a book leaves the links between those three
working and drops the rest rather than pointing them at nothing.
`Doc.SetOutline` writes an outline of your own instead, which is what a
document assembled from several files needs.

A table of contents is usually written down before it is a tree, so the grammar
for that lives in the library rather than in the command:

```go
marks, err := ops.ParseOutline("Introduction\t1\n  Why\t2\nChapter one\t7\n")
if err != nil {
    return err // "line 3: expected a title, a tab and a page number"
}
doc.SetOutline(marks)
```

One entry a line — a title, a **tab**, a page number — with two spaces of indent
for each level under another. A line it cannot read is an error **naming the
line**, because a table of contents quietly missing an entry is worse than one
that refuses to be written: the first is a document that looks finished and
sends a reader to the wrong page.

`ops.Nest([]Level) ([]Bookmark, error)` is the same function without the parser
in front of it, for a caller that already has the entries — a title, a page and
a depth in reading order, which is what an `/Outlines` tree looks like once it
has been walked. A row more than one level under the row before it is a
`*ops.DepthError` naming the row. The browser workbench reads a document's own
bookmarks that way before adding one to them, and `pdfops outline -from` reads
the file; both go through the same code, so there is one grammar rather than
two that have to be kept in step. `ops.Flatten` is `Nest` the other way round.

### The printed kind

The `/Outlines` tree is the table of contents a reader *navigates* by.
`Doc.ContentsPage` writes the one that gets **printed** — a page with a line for
each entry, its page number at the right and dots leading to it — from the same
entries:

```go
n, err := doc.ContentsPage(marks, ops.ContentsOptions{})
if err != nil {
    return err
}
doc.SetOutline(ops.ShiftBookmarks(marks, 1, n)) // if you want both
```

⛔ **The numbers it prints are moved by the pages it adds.** A contents page put
in front of a document pushes every page of it down, so an entry that pointed at
page 7 is on page 8 afterwards, and printing the 7 would send a reader one page
short of every heading in the book. `ContentsPage` returns how many pages it
added, and `ShiftBookmarks(marks, from, by)` is the same rule for the tree —
a function rather than a line in each caller because of its edge: an entry
pointing at a page *before* the insertion has not moved, and shifting that too
goes wrong in exactly the documents that have a preface.

It runs onto as many pages as it needs, and refuses rather than printing a line
whose title has no room at all: a page number with nothing to read beside it
cannot be told from a document whose headings have no names. The refusal comes
before a page is inserted, so a document that was refused is untouched.

`pdfops contents -from toc.txt -bookmarks book.pdf out.pdf` does both from one
file, and `-title`, `-before`, `-size` and `-margin` set the rest.

## On the command line

```
pdfops merge out.pdf a.pdf b.pdf
pdfops select -pages 4-6 report.pdf extract.pdf
pdfops nup -n 4 slides.pdf handout.pdf
pdfops watermark -text CONFIDENTIAL contract.pdf marked.pdf
pdfops place -image signature.png -at bottom-right -width 120 contract.pdf signed.pdf
pdfops encrypt -user letmein -allow print,copy plain.pdf locked.pdf
pdfops -password letmein permissions locked.pdf
pdfops text -layout -pages 1 paper.pdf
pdfops images paper.pdf pictures/
pdfops deskew scan.pdf straight.pdf
```

## What the corpus says

Every verb is measured on all 118 863 files rather than on a fixture. The
campaigns found nine defects no unit test would have — a stamp that fell off
pages smaller than the margin, links that dragged a source file's whole page
tree into a one-page extract, bookmarks dropped for being broken when they had
been broken in the source, and an empty owner password in AES-256 that let any
password open the file with every permission.

118 833 of 118 833 files compress and read back **page for page identical**:
35.2 GB down to 33.6 GB.
